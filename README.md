# Poker Royale starter
Flutter front-end prototype for a social poker game using virtual coins only.

Includes home screen, colored table tiers, 8-seat demo table, private room preview, daily/weekly/monthly sample leaderboard, and profile.

Run with Flutter installed:
```bash
flutter pub get
flutter run
```

Important: this is a UI prototype, not a finished online game. Firebase auth/database, secure server-authoritative poker rules, real multiplayer sync, and rewarded ads are not connected. Sample table actions and leaderboard values are not live. No real-money betting or cash-out.
